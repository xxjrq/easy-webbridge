# Easy WebBridge

让 Codex、Claude Code、OpenCode、WorkBuddy 等 AI Agent 直接操作你已经登录的 Chrome、Edge、QQ 浏览器、Chromium 或 EasyBR 多开环境，不需要重复登录网页。

## 能做什么

- 按 `browserId` 精确选择一个浏览器环境，默认按任务创建独立标签组。
- 打开页面、读取 DOM、点击、输入、截图、执行受控脚本和上传本地文件。
- 复用后台、创作者平台、应用商店等现有登录状态。
- 配合多个业务 Skill 完成抖音研究、多账号协同、内容上传和应用上架。

## 使用

先从 [GitHub](https://github.com/xxjrq/easy-webbridge) 安装运行时和浏览器扩展；GitHub 连接不稳定时使用 [Gitee 备用镜像](https://gitee.com/xxjrq/easy-webbridge)。启动后让 Agent 列出在线浏览器，并明确提供目标 `browserId`。

完整安装和使用说明见 [Easy WebBridge 帮助中心](https://www.ebrower.com/helperdoc/easy-webbridge.html)。
