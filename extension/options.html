本地连接

服务只监听 127.0.0.1，不会开放到局域网。

默认地址通常无需修改。

令牌保存在 ~/.easy-webbridge/bridge-token

浏览器身份

每个浏览器或 Profile 使用独立名称、颜色和 ID。

名称会显示在 Agent 的浏览器列表中。

身份颜色

此 ID 自动生成且保持稳定，用于精确路由 Agent 指令。

启动本地服务

在 Easy WebBridge 项目目录中运行：

npm start

然后复制访问令牌：

pbcopy < ~/.easy-webbridge/bridge-token
只在本机通信

Bridge 默认只监听 127.0.0.1，令牌不会上传到外部服务。
