# Easy WebBridge 完整使用教程

## 1. 它怎么工作

```text
Codex / Claude Code / 其他 Agent
                  |
        127.0.0.1:17777 + 本地 Token
                  |
            Easy WebBridge
          /        |        \
   EasyBR 环境 A  环境 B   Chrome 环境 C
     独立登录状态  独立登录状态  独立登录状态
```

Bridge 只管一件事：把命令交给指定的 `browserId`。网页数据、Cookie 和浏览记录仍留在原来的浏览器环境里。

## 2. 安装并启动

```bash
git clone https://github.com/xxjrq/easy-webbridge.git
cd easy-webbridge
npm install
node cli/easy-webbridge.mjs start
```

`start` 可以重复执行。服务已经开着时，它不会再启动一份。

### 是否需要开机启动

默认不需要。每次使用前运行一次 `node cli/easy-webbridge.mjs start` 即可；它会先检查服务，已运行时不会重复启动。

只有希望电脑登录后一直保持 Bridge 在线时，才添加系统登录项：

- macOS：在“系统设置 → 通用 → 登录项”添加启动脚本，脚本执行 `cd /绝对路径/easy-webbridge && exec node src/server.mjs`。
- Windows：在“任务计划程序”创建“登录时运行”任务，程序使用 Node.js 完整路径，参数为 `src/server.mjs`，起始位置为 Easy WebBridge 仓库目录。

完成后用 `node cli/easy-webbridge.mjs status` 验证。关闭登录项即可取消开机启动；不会影响扩展、登录态或 Token。扩展不能代替系统权限自动启动 Node 服务。

检查状态和在线环境：

```bash
node cli/easy-webbridge.mjs status
node cli/easy-webbridge.mjs list
```

## 3. 加载扩展

1. 在需要控制的浏览器环境中打开 `chrome://extensions`。
2. 开启“开发者模式”。
3. 选择“加载未打包的扩展程序”。
4. 选择项目中的 `extension/` 目录。
5. 对每个需要控制的 EasyBR 环境重复一次。

EasyBR 默认启动页带有环境 ID。扩展读到 ID 和环境名称后，会设置好 `browserId`、颜色并连接本地 Bridge。

## 4. 登录状态会不会丢

不会。加载扩展不清空浏览器数据，也不搬 Cookie。操作抖音、GitHub、Gitee 时，Agent 用的就是这个环境现有的登录状态。

登录状态只有在以下情况才会失效：

- 用户自己退出账号；
- 网站主动让登录过期；
- 用户清除该环境的 Cookie 或用户数据；
- 浏览器环境被删除。

Easy WebBridge 不会主动退出账号或清理数据。

## 5. 基础命令

先从 `list` 输出中复制目标 `browserId`：

```bash
node cli/easy-webbridge.mjs list
```

打开页面：

```bash
node cli/easy-webbridge.mjs navigate <browserId> https://example.com --new-tab
```

读取页面并取得 `@e1`、`@e2` 等元素引用：

```bash
node cli/easy-webbridge.mjs snapshot <browserId> <tabId>
```

日常 Agent 操作建议使用紧凑、限定范围的快照，避免重复输出整页文字：

```bash
node cli/easy-webbridge.mjs snapshot <browserId> <tabId> --compact --region viewport --max-elements 40
```

默认只返回可见交互元素并限制为 200 个。大型后台页面建议增加筛选：

```bash
# 当前视口内可见按钮
node cli/easy-webbridge.mjs snapshot <browserId> <tabId> --region viewport --role button --max-elements 30 --text-mode matched

# 指定弹窗内包含“确定”的控件
node cli/easy-webbridge.mjs snapshot <browserId> <tabId> --scope '[role=dialog]' --text 确定

# 读取隐藏元素，或将 hidden 改为 all 同时读取可见和隐藏元素
node cli/easy-webbridge.mjs snapshot <browserId> <tabId> --visibility hidden --max-elements 50
```

支持 `visible / hidden / all`、CSS 区域、视口或坐标区域、元素数量和偏移分页、文字与角色筛选。结果中的 `counts` 和 `truncated` 用来判断是否还有未返回的数据。

0.6.0 可为连续的确定性动作使用有界 batch，减少 Agent 往返；最多 20 步，只允许 `click`、`fill`、`scroll`、`wait_for`、`press_key`、`key_combo`，并可在每步后做有限断言。键盘命令发送正常 CDP key event，不修改 navigator、webdriver、Canvas、Audio、WebGL、UA、时区、代理/IP，也不绕过 CAPTCHA 或检测：

```bash
node cli/easy-webbridge.mjs batch <browserId> '{"tabId":123,"maxDurationMs":30000,"actions":[{"action":"fill","args":{"selector":"@e3","value":"内容"}},{"action":"click","args":{"selector":"@e2"},"assert":{"text":"已保存","state":"visible","timeoutMs":5000}}]}'

node cli/easy-webbridge.mjs press-key <browserId> Enter 123
node cli/easy-webbridge.mjs key-combo <browserId> '["CTRL","A"]' 123

浏览器画像采用用户明确选定的 Chrome/Edge/EasyBR Profile。需要稳定的语言、时区、隐私或站点设置时，应在该 Profile 中由用户配置并审计；Bridge 不提供画像修改、stealth、随机轨迹或检测规避能力，也不会修改 webdriver、Canvas/WebGL/Audio、UA、代理/IP。

可使用 `environment_info`（别名 `browser_profile`）读取当前顶层页面的实际 UA、platform、语言、时区、硬件并发数、可选 deviceMemory、屏幕/DPR 和 webdriver 状态。结果带 `mutated:false` 与 `source:"browser-runtime"`，只用于诊断一致性，不读取页面正文、Cookie、Token，也不支持覆盖或伪装。
```

快照可用 `--max-bytes` 设置硬输出上限；通用命令可在 `args.resultBudget` 中设置 `{ "maxBytes": 200000, "mode": "summary" }`，超限对象只返回结构摘要，不回显原始 Cookie、Token、表单值或响应正文。batch 和预算都不能替代动作后的业务状态确认。

点击和填写：

```bash
node cli/easy-webbridge.mjs click <browserId> @e2 <tabId>
node cli/easy-webbridge.mjs fill <browserId> @e3 "要填写的内容" <tabId>
node cli/easy-webbridge.mjs click <browserId> @e3 <tabId> --mode native
```

需要操作 iframe 时，先用 `list_frames` 获取临时 `frameId`，快照响应会携带该 ID，后续 click/fill 必须使用同一个 ID。跨域 OOPIF 可能可被列出但无法由 `chrome.scripting` 注入；此时会明确报错，不承诺通用支持。开放 Shadow DOM 可发现和按 `@e` 交互，关闭 Shadow DOM 不可访问。`wait` 支持 `attached / detached / visible / hidden`；`capabilities` 查看已声明和已授予权限，不会额外申请。Native 点击是成对 CDP 鼠标事件，仅限顶层 frame。

## 6. 任务会话和标签组

给同一任务的命令传入相同 `session`，新标签会自动进入同一个浏览器标签组：

```bash
node cli/easy-webbridge.mjs command <browserId> navigate \
  '{"url":"https://www.douyin.com/","newTab":true,"session":"douyin-analysis","groupTitle":"抖音数据分析"}'
```

查找任务里的标签：

```bash
node cli/easy-webbridge.mjs command <browserId> find_tab \
  '{"url":"https://www.douyin.com/","session":"douyin-analysis"}'
```

借用用户当前正在看的已登录标签，不把它加入 Agent 标签组：

```bash
node cli/easy-webbridge.mjs command <browserId> find_tab \
  '{"url":"douyin.com","active":true,"session":"douyin-analysis"}'
```

关闭该任务创建的全部标签：

```bash
node cli/easy-webbridge.mjs command <browserId> close_session \
  '{"session":"douyin-analysis"}'
```

借用的用户标签不会被 `close_session` 关闭。

## 7. 截图

当前视口：

```bash
node cli/easy-webbridge.mjs screenshot <browserId> <tabId>
```

完整页面：

```bash
node cli/easy-webbridge.mjs command <browserId> screenshot \
  '{"tabId":123,"fullPage":true,"format":"png"}'
```

单个元素：

```bash
node cli/easy-webbridge.mjs command <browserId> screenshot \
  '{"tabId":123,"selector":"@e8","format":"png","path":"/absolute/output.png"}'
```

截图默认保存在 `~/.easy-webbridge/screenshots/`。

## 8. 网络请求

开始记录：

```bash
node cli/easy-webbridge.mjs command <browserId> network \
  '{"tabId":123,"cmd":"start"}'
```

刷新或操作页面后查看请求：

```bash
node cli/easy-webbridge.mjs command <browserId> network \
  '{"tabId":123,"cmd":"list","filter":"api","limit":200}'
```

查看单条请求详情和响应正文：

```bash
node cli/easy-webbridge.mjs command <browserId> network \
  '{"tabId":123,"cmd":"detail","requestId":"123.45","includeBody":true}'
```

停止记录：

```bash
node cli/easy-webbridge.mjs command <browserId> network \
  '{"tabId":123,"cmd":"stop"}'
```

网络详情可能包含账号数据或接口 Token。Agent 不应把 Cookie、Authorization、密码和私人响应正文输出到聊天或日志。

## 9. 保存 PDF

```bash
node cli/easy-webbridge.mjs command <browserId> save_as_pdf \
  '{"tabId":123,"paper_format":"a4","print_background":true,"path":"/absolute/output.pdf"}'
```

PDF 默认保存在 `~/.easy-webbridge/pdf/`。

## 10. 上传、Cookie、下载和 CDP

```bash
node cli/easy-webbridge.mjs command <browserId> upload \
  '{"tabId":123,"selector":"input[type=file]","files":["/absolute/path/file.png"]}'

node cli/easy-webbridge.mjs command <browserId> get_cookies \
  '{"filter":{"domain":"example.com"}}'

node cli/easy-webbridge.mjs command <browserId> download \
  '{"url":"https://example.com/file.zip","saveAs":false}'

node cli/easy-webbridge.mjs command <browserId> cdp \
  '{"tabId":123,"method":"Page.reload","params":{}}'
```

文件上传目前只支持顶层 frame；传入非零 `frameId` 会明确返回不支持。真实 Stitch OOPIF 和 iframe 文件上传尚未验收，不能用坐标点击或重复提交代替。

## 11. 更新扩展

从 `0.2.1` 开始，可以远程重载指定环境的扩展：

```bash
node cli/easy-webbridge.mjs command <browserId> reload_extension '{}'
```

命令会先返回确认，再重载扩展并自动连接回来。修改扩展源码并跨越旧版本能力时，第一次仍需要在 `chrome://extensions` 手动点击一次刷新。

## 13. 常见问题

### 扩展显示未连接

执行：

```bash
node cli/easy-webbridge.mjs start
node cli/easy-webbridge.mjs status
```

然后在扩展弹窗中点击“重新连接”。

### 找不到目标浏览器

运行 `list`，确认目标环境在线，并使用返回结果中的完整 `browserId`。不要只用浏览器名称猜测。

### 为什么浏览器提示“正在调试”

网络查看、PDF、元素截图、文件上传和原始 CDP 都要用 Chromium 的 `debugger` 权限。普通 Chrome/Chromium 会显示原生调试提示，扩展本身无法隐藏或美化这条浏览器安全提示。

EasyBR 已在浏览器启动层默认隐藏这条提示，完整保留上述能力。设置入口是“环境编辑 → 其他设置 → 隐藏扩展调试提示”，默认开启；更新 EasyBR 或修改此设置后，需要关闭并重新打开对应浏览器环境才能生效。

### 能否同时控制几十个环境

可以。每个环境单独连接，Bridge 根据 `browserId` 把命令送过去。到底能同时开多少个，要看电脑内存、CPU 和网页本身有多重。
