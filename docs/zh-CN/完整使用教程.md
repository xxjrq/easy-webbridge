# Easy WebBridge 完整使用教程

## 1. 它怎么工作

```text
Codex / Claude Code / 其他 Agent
                  |
        127.0.0.1:17777 + 本地 Token
                  |
            Easy WebBridge
          /        |        \
   EasyBR 环境 A  环境 B   Chrome 环境 C
     独立登录状态  独立登录状态  独立登录状态
```

Bridge 只管一件事：把命令交给指定的 `browserId`。网页数据、Cookie 和浏览记录仍留在原来的浏览器环境里。

## 2. 安装并启动

```bash
git clone https://github.com/xxjrq/easy-webbridge.git
cd easy-webbridge
npm install
node cli/easy-webbridge.mjs start
```

`start` 可以重复执行。服务已经开着时，它不会再启动一份。

检查状态和在线环境：

```bash
node cli/easy-webbridge.mjs status
node cli/easy-webbridge.mjs list
```

## 3. 加载扩展

1. 在需要控制的浏览器环境中打开 `chrome://extensions`。
2. 开启“开发者模式”。
3. 选择“加载未打包的扩展程序”。
4. 选择项目中的 `extension/` 目录。
5. 对每个需要控制的 EasyBR 环境重复一次。

EasyBR 默认启动页带有环境 ID。扩展读到 ID 和环境名称后，会设置好 `browserId`、颜色并连接本地 Bridge。

## 4. 登录状态会不会丢

不会。加载扩展不清空浏览器数据，也不搬 Cookie。操作抖音、GitHub、Gitee 时，Agent 用的就是这个环境现有的登录状态。

登录状态只有在以下情况才会失效：

- 用户自己退出账号；
- 网站主动让登录过期；
- 用户清除该环境的 Cookie 或用户数据；
- 浏览器环境被删除。

Easy WebBridge 不会主动退出账号或清理数据。

## 5. 基础命令

先从 `list` 输出中复制目标 `browserId`：

```bash
node cli/easy-webbridge.mjs list
```

打开页面：

```bash
node cli/easy-webbridge.mjs navigate <browserId> https://example.com --new-tab
```

读取页面并取得 `@e1`、`@e2` 等元素引用：

```bash
node cli/easy-webbridge.mjs snapshot <browserId> <tabId>
```

点击和填写：

```bash
node cli/easy-webbridge.mjs click <browserId> @e2 <tabId>
node cli/easy-webbridge.mjs fill <browserId> @e3 "要填写的内容" <tabId>
```

## 6. 任务会话和标签组

给同一任务的命令传入相同 `session`，新标签会自动进入同一个浏览器标签组：

```bash
node cli/easy-webbridge.mjs command <browserId> navigate \
  '{"url":"https://www.douyin.com/","newTab":true,"session":"douyin-analysis","groupTitle":"抖音数据分析"}'
```

查找任务里的标签：

```bash
node cli/easy-webbridge.mjs command <browserId> find_tab \
  '{"url":"https://www.douyin.com/","session":"douyin-analysis"}'
```

借用用户当前正在看的已登录标签，不把它加入 Agent 标签组：

```bash
node cli/easy-webbridge.mjs command <browserId> find_tab \
  '{"url":"douyin.com","active":true,"session":"douyin-analysis"}'
```

关闭该任务创建的全部标签：

```bash
node cli/easy-webbridge.mjs command <browserId> close_session \
  '{"session":"douyin-analysis"}'
```

借用的用户标签不会被 `close_session` 关闭。

## 7. 截图

当前视口：

```bash
node cli/easy-webbridge.mjs screenshot <browserId> <tabId>
```

完整页面：

```bash
node cli/easy-webbridge.mjs command <browserId> screenshot \
  '{"tabId":123,"fullPage":true,"format":"png"}'
```

单个元素：

```bash
node cli/easy-webbridge.mjs command <browserId> screenshot \
  '{"tabId":123,"selector":"@e8","format":"png","path":"/absolute/output.png"}'
```

截图默认保存在 `~/.easy-webbridge/screenshots/`。

## 8. 网络请求

开始记录：

```bash
node cli/easy-webbridge.mjs command <browserId> network \
  '{"tabId":123,"cmd":"start"}'
```

刷新或操作页面后查看请求：

```bash
node cli/easy-webbridge.mjs command <browserId> network \
  '{"tabId":123,"cmd":"list","filter":"api","limit":200}'
```

查看单条请求详情和响应正文：

```bash
node cli/easy-webbridge.mjs command <browserId> network \
  '{"tabId":123,"cmd":"detail","requestId":"123.45","includeBody":true}'
```

停止记录：

```bash
node cli/easy-webbridge.mjs command <browserId> network \
  '{"tabId":123,"cmd":"stop"}'
```

网络详情可能包含账号数据或接口 Token。Agent 不应把 Cookie、Authorization、密码和私人响应正文输出到聊天或日志。

## 9. 保存 PDF

```bash
node cli/easy-webbridge.mjs command <browserId> save_as_pdf \
  '{"tabId":123,"paper_format":"a4","print_background":true,"path":"/absolute/output.pdf"}'
```

PDF 默认保存在 `~/.easy-webbridge/pdf/`。

## 10. 上传、Cookie、下载和 CDP

```bash
node cli/easy-webbridge.mjs command <browserId> upload \
  '{"tabId":123,"selector":"input[type=file]","files":["/absolute/path/file.png"]}'

node cli/easy-webbridge.mjs command <browserId> get_cookies \
  '{"filter":{"domain":"example.com"}}'

node cli/easy-webbridge.mjs command <browserId> download \
  '{"url":"https://example.com/file.zip","saveAs":false}'

node cli/easy-webbridge.mjs command <browserId> cdp \
  '{"tabId":123,"method":"Page.reload","params":{}}'
```

## 11. 更新扩展

从 `0.2.1` 开始，可以远程重载指定环境的扩展：

```bash
node cli/easy-webbridge.mjs command <browserId> reload_extension '{}'
```

命令会先返回确认，再重载扩展并自动连接回来。修改扩展源码并跨越旧版本能力时，第一次仍需要在 `chrome://extensions` 手动点击一次刷新。

## 13. 常见问题

### 扩展显示未连接

执行：

```bash
node cli/easy-webbridge.mjs start
node cli/easy-webbridge.mjs status
```

然后在扩展弹窗中点击“重新连接”。

### 找不到目标浏览器

运行 `list`，确认目标环境在线，并使用返回结果中的完整 `browserId`。不要只用浏览器名称猜测。

### 为什么浏览器提示“正在调试”

网络查看、PDF、元素截图和原始 CDP 都要用 Chromium 的 `debugger` 权限，所以浏览器会显示调试提示。这是正常现象。

### 能否同时控制几十个环境

可以。每个环境单独连接，Bridge 根据 `browserId` 把命令送过去。到底能同时开多少个，要看电脑内存、CPU 和网页本身有多重。
